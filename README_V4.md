# 学习通自动刷课 + 刷题助手 V4

V4 是在 [chaolucky18/xuexitongScript](https://github.com/chaolucky18/xuexitongScript) 的 V3 油猴脚本基础上扩展的单文件版本。保留了原来的视频自动播放、跨章切换小节能力，并增加章节测验、视频内嵌弹题自动作答和目录节点自动跳过。

> 感谢原项目 **chaolucky18/xuexitongScript** 及所有贡献者提供的 V3 基础实现和页面结构经验。

## 主要功能

- **自动播放**：识别 iframe 内的视频，自动播放、恢复暂停、处理播放中断。
- **跨章切节**：按整棵课程目录顺序切换，不依赖平台经常不更新的 `posCatalog_active`。
- **自动跳过**：已完成节点、待完成任务点为 0 的节点不再点开；当前页已是这类节点时也会自动切到下一节。
- **章节测验**：识别单选题、多选题、判断题，调用 DeepSeek 作答，校验答案后提交。
- **视频弹题**：自动识别视频中弹出的题目，作答并点击“继续播放”；答错会按配置重试，最多 3 次。
- **本地题库**：按“题型 + 题干”保存答对的选项文本，下次遇到同一题优先命中；答错会自动移除错题，避免污染题库。
- **手动控制**：面板提供“立即答题”“识别题目”“清空题库”等按钮。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [xuexitong_v4_quiz.user.js](./xuexitong_v4_quiz.user.js)，在 Tampermonkey 中新建脚本并粘贴全部内容；或直接访问 raw 地址安装。
3. 打开学习通课程播放页，刷新页面。
4. 在右下角“学习通助手 V4”面板中填写 DeepSeek API Key，点击“保存”。

raw 安装地址：

```text
https://raw.githubusercontent.com/Meow1s/xuexitongScript/master/xuexitong_v4_quiz.user.js
```

## 配置说明

面板默认开启：

- 自动播放
- 自动答题（章节测验）
- 视频题（视频内嵌弹题）
- 自动提交
- 题库优先

DeepSeek 配置：

- API 地址默认 `https://api.deepseek.com`
- 模型默认 `deepseek-chat`
- API Key 只保存在 Tampermonkey 的本地存储中，由脚本直接请求 DeepSeek，不经过第三方服务

## 视频弹题重试

默认最多尝试 3 次：

1. 第一次答错后，脚本会清理旧选择并重试；
2. 重试请求会带上一次答案，提示模型逐题复核；
3. 如果平台提供“返回重做”，脚本会点一次再重试；
4. 达到上限后保留弹窗并暂停自动播放，避免反复提交。

答对后才会把本题写入题库；答错会从题库移除对应记录。

## 目录跳过规则

脚本会综合以下信号判断一个目录节点是否已经无需学习：

- 完成图标：`icon_Completed` 等；
- 待完成任务点计数：`jobUnfinishCount=0`；
- 行内 `0`、`0个任务点`、`0/0` 徽章；
- 节点/标题/行级 `completed`、`finished`、`done` 等 class；
- “已完成/完成”状态文本。

跳过时控制台会输出原因和节点标题。若平台只用纯背景图表示完成状态、且没有文本或计数属性，需要提供该节点的 `outerHTML` 才能继续精确适配。

## 已知限制

- 只处理**章节测验**和**视频内嵌弹题**，不处理考试、作业、讨论等题型。
- 章节测验的页面结构可能随平台更新变化，脚本会做稳定性等待和重试，但不能保证所有课程模板一致。
- API Key 需要用户自行准备；没有 Key 时脚本会停止答题并提示。
- 默认不会自动跳过无法识别的无视频页面，避免误跳过需要阅读的课件。可在面板中开启“无视频自动下一节”，或确认当前节点无需处理后手动执行 `app.nextUnit()`。
